# GGHV Lean formalization — parts index

Paper: Guccione, Guccione, Horruitiner, Valqui, "Increasing the
degree of a possible counterexample to the Jacobian Conjecture
from 100 to 108", arXiv:2204.14178v1. TeX source:
`~/workspace/research/rss-monitor/tex/2204.14178/main.tex`.

## How to compile

Parts 1–9 and 13 use core Lean only, so they compile standalone with the
project toolchain (Lean 4.34.0); Parts 10–12 use Mathlib and build via lake:

```
~/.elan/bin/lean JC2/GGHV/Part1_Cases.lean
```

or, for all parts at once (also checks for sorry/admit/axiom
declarations):

```
bash JC2/GGHV/compile_all.sh
```

A lake project with Mathlib v4.34.0 is set up in the parent
`Lean4/` directory and builds (see the Lake project bullet
below); Parts 10–12 import Mathlib (D2/D3, compiled 2026-10-30).
